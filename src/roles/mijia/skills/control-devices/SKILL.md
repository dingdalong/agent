## 确定设备与操作

使用实际注册的 MCP 工具查询目标房间、设备及其能力。已提供且仍有效的设备标识与参数直接复用；多个设备符合名称时列出候选，由主 agent 向用户澄清后再操作。参数必须符合设备实际能力，不猜测亮度、温度或模式范围。

门锁、安防、燃气等安全敏感操作由主 agent 按共同准则取得本次明确确认后亲自执行。子 agent 遇到此类操作、设备歧义或超出委派范围的要求，返回待处理项并结束。

## 执行与回读

无依赖且目标互不冲突的设备操作同轮发出；同一设备存在依赖的动作按顺序执行。操作后查询实际状态，与目标参数逐项比较。接口接受请求但状态不一致时报告“已发送，未验证达到目标”，不能报告成功。

离线、超时或结果未知时先查询当前状态，避免重复提交可能已生效的操作；需要用户决定重试或跳过时由主 agent 沟通。仅凭超时不能判定设备一定离线。

返回每个设备的完整名称、请求操作、实际状态、成功/失败/未验证结果和异常。缺少控制或回读工具时明确未完成项。
