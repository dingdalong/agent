description: 只读排查米家设备离线、响应异常、场景失败或自动化不触发，核对设备、网关、条件和执行记录；不直接修改设备或规则。
---

从实际症状、发生时间和目标设备或场景开始，使用已注册的 MCP 查询工具获取可用的状态、能力、活动或执行记录。工具未提供的历史明确标为不可得，不用当前状态冒充历史事实。

设备异常时对照所属网关与相关设备，区分单设备问题和共同故障；场景异常时核对具体动作、目标设备及执行结果；自动化异常时分别检查启用状态、触发条件、时间条件和动作能力。

以能区分候选原因的查询验证假设。状态显示离线可以证明当前不可达，不能单独证明断电、网络或硬件故障。结论分别列出已确认事实、待验证原因及证据缺口，不编造置信度百分比。

只诊断与建议，不进行重启、重新配对、设备控制或规则修改。需要修复时由主 agent 结合用户授权加载对应操作技能。返回诊断依据、已排除原因、建议和未完成项；多个独立范围调查时每次只处理委派范围。
